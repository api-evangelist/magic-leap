# Magic Leap

> Magic Leap is an augmented reality company building see-through AR optics
> (waveguides, display systems) and the Magic Leap 2 enterprise AR headset,
> plus a developer platform for building spatial computing applications on
> device using Unity, OpenXR, and a native C API. Backed by a16z, Kleiner
> Perkins, and Obvious Ventures.

## Developer Platform

- [Magic Leap 2 Developer Portal](https://ml2-developer.magicleap.com/): Hub for getting started, downloads, release notes, and device flashing guides.
- [Developer Documentation](https://developer-docs.magicleap.cloud/): Learn Magic Leap 2 — SDK guides, API/runtime reference, and tutorials.
- [Developer Downloads](https://ml2-developer.magicleap.com/downloads): Magic Leap Hub and Magic Leap 2 developer tools.
- [GitHub Organization](https://github.com/magicleap): 43+ public repos — Unity SDK examples, MRTK3, LeapBrush AR Cloud reference app, XR keyboard, spatial mesh tooling.

## SDKs and Standards

- Magic Leap Unity SDK (distributed via Magic Leap Hub package registry).
- MagicLeapUnityMRTK3 (Mixed Reality Toolkit 3 integration).
- OpenXR runtime + native C API for on-device development.

## Note on API Surface

- Magic Leap is a device SDK / spatial-computing platform. It does not publish a public hosted REST API or OpenAPI specification; integration is on-device via the SDKs above.

## Security and Compliance

- Certifications: ISO/IEC 27001:2022, SOC 2 Type II.
- Third-party integration security requirements published on magicleap.com.
